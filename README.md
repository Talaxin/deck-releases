# Deck releases

Public AltStore / [Feather](https://github.com/khcrysalis/Feather) source for **Deck**, a native iPhone wardriving HUD for WDGWars.

This repo holds only the source feed, icon, and unsigned IPAs. No app source code lives here (that stays in a private repo).

## Add in Feather

1. Open Feather → **Sources** → add source.
2. Paste:

   ```
   https://raw.githubusercontent.com/Talaxin/deck-releases/main/source.json
   ```

3. Install **Deck** (`com.ceph.warmap`). Feather signs the unsigned IPA on your device.
